One word, one username, one reward: this entry sends the entrant's own make.fun handle, `mouns`, and nothing else. A judge model reads two usernames at a time and picks the one that feels funnier or more interesting; `mouns` is short, single-word, and unmistakably a handle its owner wears. The program writes exactly those five characters to `/output/entry.txt`, inside the kit's 1–30 character gate.

## Run it

```sh
node main.ts /output
```
